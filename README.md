# Abuela’s Tamales

A small, portable family recipe website. Plain HTML, CSS and JavaScript; no build tools or database.

## Update the page
Edit `index.html` for words and `styles.css` for layout. `family-video.jpg` is the preview image. Check the page on a phone and computer before committing changes. GitHub Pages publishes the main branch root.

## Update the video
`video-config.js` contains the HTTPS URL of the viewing copy. The video is hosted in the family’s personal AWS account through CloudFront, with a private S3 origin. Keep the video out of GitHub. Upload a new approved versioned filename, update the scoped origin policy and this URL, then test playback, sound and seeking. Keep older master files in the family archive.

## Preserve the family archive
The website is not a backup. Preserve the original Christmas Tamales.mp4 and compressed viewing copy in at least two independent places; sync alone is not backup. Test backups yearly and before retiring a computer.

## Ownership and renewals
The domain is registered at Squarespace; this repository and Pages host the website; the family’s personal AWS account delivers the video. Keep these accounts active, review renewal reminders, and designate a trusted successor with appropriate access. Store credentials and recovery instructions privately, never in this repository. Move and test video delivery before closing its hosting account.

## Sharing
This website and video are public and can be copied or shared. Music rights are not cleared by hosting the video. No analytics or external fonts are included; video requests start when the visitor presses play.
